=== Hide Atelier ===
Requires at least: 6.3
Tested up to: 6.8
Requires PHP: 7.4
License: GPLv2 or later

Premium WooCommerce theme for leather jacket stores.

== Installation ==
1. Install and activate WooCommerce.
2. Upload and activate this theme.
3. Go to Appearance → Hide Atelier Setup and click "Run setup".
4. Edit your store details in Appearance → Customize → Hide Atelier.
